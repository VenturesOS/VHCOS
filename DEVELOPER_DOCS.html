1. Quick Start Guide

Setup Commands

# Backend Setup
cd /app/backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001 --reload

# Frontend Setup
cd /app/frontend
yarn install
yarn start

Environment Variables

Backend (.env)

MONGO_URL=mongodb+srv://...
DB_NAME=vhc_talent_os
JWT_SECRET_KEY=...
EMERGENT_LLM_KEY=...
UPSTASH_REDIS_REST_URL=...
R2_ACCOUNT_ID=...

Frontend (.env)

REACT_APP_BACKEND_URL=https://your-domain.com

8. AI Matching System

⚡ Quick Match (Default)

  • Speed: 2-5 seconds
  • Method: Keyword + semantic scoring
  • LLM Calls: Zero
  • Best for: Fast screening

🧠 Full AI Match

  • Speed: 1-3 minutes
  • Method: LLM deep analysis
  • Runs: Background job
  • Best for: Detailed matching

Matching Flow

// 1. Start matching
POST /api/matching/find-candidates
Body: { "job_id": "...", "match_mode": "quick" }

// 2. For Full AI, poll status
GET /api/matching/jobs/{job_id}/status
Response: { "status": "completed", "progress": 100, "results": [...] }

// 3. Shortlist candidate
POST /api/matching/shortlist
Body: { "candidate_id": "...", "job_id": "..." }
