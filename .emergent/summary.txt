**PRODUCT REQUIREMENTS (current focus)**
1.  **Visibility**: Admin, Employer, and Recruiter must be able to view a candidate's current salary (INR), notice period, skills, and experience summary on the Applicant Review screen.
2.  **Controlled Editing**: These roles must be able to edit the same fields, but only within an explicit Edit Details mode. The view should be read-only by default.
3.  **Data Precedence**: Manual edits must always override AI-parsed data. Subsequent resume parsing should not overwrite manual edits.
4.  **Audit & Safety**: Log every edit (field, old value, new value, user, timestamp) and display a Last updated by indicator in the UI.
5.  **UX Constraints**: Editing is restricted to the specified fields. Identity fields (email/phone), job history, and the resume file itself cannot be changed in this flow.
