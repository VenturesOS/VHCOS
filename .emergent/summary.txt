**original_problem_statement:**
The user wants to build a production-ready, role-based recruitment portal called VHC Talent OS.

**PRODUCT REQUIREMENTS (Phase-1 & 2)**
- **Roles**: Admin, Recruiter, Employer, Candidate.
- **Authentication**: JWT-based email/password login with role-based access control.
- **Dashboards**: Dedicated dashboards for each role with specific functionalities:
    - **Admin**: Full control over users, jobs, candidates, companies, and system settings.
    - **Recruiter**: Manage assigned jobs, upload resumes, and move candidates through a pipeline (Applied, Shortlisted, Interview, Offered, Hired).
    - **Employer**: Post jobs, view applicants, and see basic job analytics.
    - **Candidate**: Create a profile, upload a resume, apply for jobs, and track application status.
- **Branding**: Clean, professional UI using a color palette derived from the provided VHC logo.
- **Tech Stack**: FastAPI (Backend), React (Frontend), MongoDB (Database).
- **Security**: Hardened access control, secure admin creation (environment-based seeding), and mandatory password reset on first login for all new users.
- **AI Matching Engine (Phase-2b)**:
    - Parse job descriptions and resumes using OpenAI GPT-5.2.
    - Find Matching Candidates feature for Employers/Recruiters with filterable must-have conditions.
    - Automatic job matching for candidates based on their resumes.
- **Candidate Data Bank (Phase-2b)**:
    - A centralized, single source of truth for all candidate data.
    - Logic for deduplicating candidates based on email, phone, or resume hash.
    - Audit trail for all data changes.
    - History of resume versions for each candidate.

**User's preferred language**: English
